# Fundamental Computer Vision Lab

This repository contains the programs and implementations completed as part of the **Fundamental Computer Vision (FCV) Laboratory**.

The lab focuses on understanding core concepts in computer vision using **Python, OpenCV, NumPy, and Matplotlib**, progressing from basic image processing to advanced topics such as feature matching, camera calibration, and object tracking.

---

## Course Objectives

The laboratory is designed to help students:

* Understand fundamental concepts of computer vision.
* Implement image processing and enhancement techniques.
* Perform image filtering and segmentation.
* Extract and analyze image features.
* Understand and implement feature matching techniques.
* Perform camera calibration.
* Implement object tracking methods.
* Apply computer vision concepts through mini projects.

## Topics Covered

### 1. Introduction to OpenCV using Python

Introduction to computer vision programming using OpenCV and Python.

Topics include:

* Reading and displaying images
* Image properties
* Color spaces
* Grayscale conversion
* Pixel manipulation
* Basic image operations

### 2. Image Enhancement Techniques

Implementation of techniques used to improve image quality and visual appearance.

Topics include:

* Image negative
* Log transformation
* Power-law transformation
* Piecewise linear transformation
* Contrast enhancement
* Histogram processing
* Histogram equalization

### 3. Image Filtering Operations

Study and implementation of spatial filtering techniques.

Topics include:

* Mean filtering
* Gaussian filtering
* Median filtering
* Smoothing
* Image sharpening
* Unsharp masking
* Gradient-based edge detection
* Sobel operators

### 4. Image Segmentation Methods

Techniques for dividing an image into meaningful regions.

Topics include:

* Thresholding
* Binary image generation
* Color-based segmentation
* Region-based segmentation
* K-Means clustering

### 5. Feature Extraction Techniques

Extraction of important visual features from images.

Topics include:

* Edge detection
* Corner detection
* Shape features
* Contour extraction
* Feature descriptors

### 6. Mini Project – Phase I

Application of the concepts learned in the initial laboratory sessions to develop a computer vision-based mini project.

### 7. Feature Matching Methods

Techniques for finding correspondences between features in different images.

Topics include:

* Feature detection
* Feature descriptors
* Feature matching
* Matching evaluation

### 8. Camera Calibration

Understanding and implementing camera calibration techniques.

Topics include:

* Camera parameters
* Calibration patterns
* Chessboard detection
* Intrinsic parameters
* Extrinsic parameters
* Distortion correction

### 9. Tracking Methods

Implementation of techniques for tracking objects across video frames.

Topics include:

* Object detection
* Object tracking
* Motion analysis
* Tracking across frames

### 10. Mini Project – Phase II

Further development and completion of the computer vision mini project by integrating advanced concepts learned throughout the laboratory.

### 11. Mini Project Evaluation

Evaluation and demonstration of the completed mini project.

### 12. Lab End Semester Examination

Practical examination covering the concepts and implementations studied throughout the laboratory.
